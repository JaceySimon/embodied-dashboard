# 产品分析：具身智能看板

## 一、用户是谁？

### 核心用户（优先服务）

**1. 博士生 / 研究员（最核心）**
- 每天花 1-2 小时读论文
- 痛点：信息过载，不知道哪些是真前沿
- 他们需要：快速了解本周领域进展，找到值得精读的论文
- 他们在哪：arXiv、Twitter、GitHub

**2. 教授 / 实验室负责人**
- 每周花 1-2 小时了解领域动态
- 痛点：没时间读论文，需要知道方向变化
- 他们需要：每周简报，知道哪些方向在升温
- 他们在哪：会议、推荐信、基金申请

**3. 工业界研究员（PI、DeepMind、NVIDIA）**
- 每天花 30 分钟了解竞品动态
- 痛点：不知道其他公司在做什么
- 他们需要：竞品追踪，知道谁在发布什么
- 他们在哪：公司博客、发布会

### 次要用户（后续扩展）

**4. 投资者 / 分析师**
- 每周花 1-2 小时了解行业动态
- 痛点：需要知道技术趋势，判断投资方向
- 他们需要：行业趋势分析，技术成熟度评估

**5. 学生（想进入这个领域）**
- 每周花 2-3 小时学习
- 痛点：不知道从哪里开始学
- 他们需要：学习路径，经典论文推荐

---

## 二、痛点是什么？

### 痛点 1：信息过载
- 每天有 50+ 篇机器人论文
- 大部分是重复的、增量的、不前沿的
- 用户不知道哪些值得读

### 痛点 2：信息分散
- 论文在 arXiv
- 技术报告在公司博客
- 讨论在 Twitter
- 代码在 GitHub
- 用户需要跳 4 个网站才能了解一个事件

### 痛点 3：信噪比低
- 很多论文是刷榜的，不是真的前沿
- 很多博客是营销的，没有技术含量
- 用户不知道哪些是真东西

### 痛点 4：时间宝贵
- 博士生每天只有 1-2 小时读论文
- 教授每周只有 1-2 小时了解领域
- 他们不想花 2 小时读 20 篇论文，只想花 10 分钟知道关键进展

---

## 三、核心价值是什么？

### 一句话
**帮研究者少读 80% 垃圾，半小时看清谁在真做、谁在刷榜。**

### 三个核心功能
1. **聚焦**：只收 VLA / 世界模型 / 仿真器，不收其他
2. **聚合**：同一事件的多个来源聚合成一条
3. **筛选**：按标签、实验室、是否开源筛选

### 为什么用户要用我们？

| | arXiv | Google Scholar | 我们 |
|---|---|---|---|
| 聚焦 | 所有领域 | 所有领域 | 只收 VLA/世界模型/仿真器 |
| 更新 | 每天 | 每天 | 每天 |
| 聚合 | 无 | 无 | 同一事件多来源聚合 |
| 筛选 | 简单 | 简单 | 按标签/实验室/是否开源 |
| AI 摘要 | 无 | 无 | 3 句话摘要 |
| 收藏 | 无 | 有 | 本地收藏 |
| 相关推荐 | 无 | 有 | 基于标签相似度 |

## 四、成功指标是什么？

### 北极星指标
**每周活跃用户数（WAU）**

### 次级指标
- 日活用户数（DAU）
- 用户平均使用时长
- 收藏数 / 用户
- 回访率（每周回访）
- 导出数 / 用户

### 质量指标
- 每周必看论文数（用户觉得"值得精读"的比例）
- 事件聚合准确率
- 标签准确率

---

## 五、用户流程是什么？

### 首次使用
1. 打开网站 → 看到"本周必看 10 篇"
2. 快速浏览 5 分钟
3. 对感兴趣的论文点进去看摘要
4. 收藏好的论文

### 每周回访
1. 打开网站 → 看到"本周新增 15 篇"
2. 快速浏览 5 分钟
3. 看"本周热点"标签
4. 看"活跃作者"

### 深度使用
1. 用搜索找特定方向
2. 用标签筛选
3. 看相关论文推荐
4. 导出收藏列表

---

## 六、MVP 应该做什么？

### 第一阶段（现在）
- 只做"本周必看 10 篇"
- 让用户 5 分钟看完本周关键进展
- 有收藏、有搜索、有筛选

### 第二阶段
- 做"每周简报"（邮件/微信推送）
- 做"竞品追踪"（特定公司的动态）
- 做"AI 摘要"（每篇论文 3 句话）

### 第三阶段
- 做"趋势分析"（哪些方向在升温）
- 做"实验室动态"（哪些实验室在发论文）
- 做"导出报告"（PDF/简报）

---
